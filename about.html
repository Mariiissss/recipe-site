О проекте

«Что приготовить?» — это учебный веб-проект, созданный в рамках изучения современных технологий веб-разработки.

🎯 Наша цель

Помочь людям находить проверенные рецепты на каждый день — от быстрых завтраков до праздничных десертов. Мы собираем рецепты, проверяем их и делимся с вами в удобном формате.

🛠 Технологии

Проект реализован на классическом фронтенд-стеке:

  • HTML5 — семантическая разметка страниц
  • CSS3 — адаптивная вёрстка, Grid, Flexbox, CSS-переменные
  • JavaScript (ES6+) — интерактивность и работа с DOM
  • localStorage — хранение данных пользователя и рецептов
  • Git и GitHub — контроль версий и публикация проекта
